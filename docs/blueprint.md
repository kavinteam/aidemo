# **App Name**: Bandhana

## Core Features:

- Hero Section: Display couple's names, wedding date, a romantic tagline, and a countdown timer.
- Love Story Timeline: Showcase the couple's journey with a scrollable timeline, including key milestones and engagement photos.
- Event Itinerary: Detail the schedule for each wedding event (Haldi, Mehendi, Sangeet, Wedding, Reception) with dates, times, venues, and dress code information.
- Venue Details & Map: Display venue addresses with an embedded Google Maps to guide guests.
- RSVP Form: Collect guest RSVPs with fields for name, number of attendees, event attendance confirmation, and meal preferences.
- Photo Gallery: Curate engagement and pre-wedding photos in a visually appealing masonry or carousel layout.
- Guest Wishes: Allow guests to leave digital messages and emojis, creating a digital guestbook.

## Style Guidelines:

- Primary color: Gold (#D4AF37) to reflect the luxurious and festive nature of the wedding.
- Background color: Off-white (#FAF9F6) for a minimal and elegant feel.
- Accent color: Maroon (#800000) to complement the gold and add a touch of traditional warmth.
- Headline font: 'Playfair', serif, for an elegant and fashionable aesthetic; body font: 'PT Sans', sans-serif, for readability.
- Incorporate Mysore palace motifs and silk saree textures as subtle background patterns or icons.
- Use a clean, minimal layout with plenty of white space to highlight content and imagery. Ensure a mobile-responsive design.
- Implement smooth scroll animations and parallax effects for an engaging user experience.
